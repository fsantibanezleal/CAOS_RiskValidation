# U15 governance: scope, inventory, tiering, lifecycle, findings, schedule, opinion, appetite, policy, report and the `gov.` tests (U15-E)

Sources: research dossier 06 of the Contraste initiative (B.1 the scope test l.523-537, B.2 the inventory attributes l.539-551, B.3 the tiering rubric
l.553-574, B.4 the lifecycle l.576-583, B.6 approval and the model risk appetite l.601-612, B.7 findings severity and remediation l.614-628, B.8 frequency
by tier l.630-640, I.2, I.3 the validation report l.1219-1237, I.6 what not to claim l.1261-1277), the U15 research addendum (D1 to D6), the unit sizing
decisions W15-1 to W15-15 and the API contract `engine-governance-api` 1.0.0 (Contraste `docs/contracts/engine/governance-api.md` on `task/u15-s` at
5dce395, after the Opus review's fix round), whose functions, units, invariants and golden values this unit implements one by one. Transcribed into
`docs/governance/`.

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated. The engine computes; it approves nothing
and certifies nothing (SDD non-goal 1; dossier 06 I.6). Every tier count, band, deadline, frequency and threshold is a stated convention (item 30 of the
dossier's UNVERIFIED list): a named parameter that carries the label `convention`, never a value taken from a regulation. The golden values are the
contract's, and the four fixtures of the contract are reproduced field by field.
