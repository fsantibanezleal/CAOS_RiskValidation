# U14 fairness: group metrics, inference on the selection rates, conditional disparity, replication, situation testing, planted bias and the fairness validation tests (U14-E2)

Sources: research dossier 06 of the Contraste initiative (section C.7 l.1029-1040 for the group metrics, the four-fifths line and the
two proportion tests; I.6 l.1268-1270 for the rule that every tolerance is a convention), dossier 04 J.3 l.897-905 (calibration and AUC
within groups), dossier 07 A.3 l.158-177 (situation testing), the U14 research addendum (H1 the HMDA field names, H3 the legal tests,
H5 the situation-testing algorithm and its golden values in section 7.6), and the API contract `engine-fairness-api` 1.0.0 (Contraste
`docs/contracts/engine/fairness-api.md`, after the Opus review's fix round), whose functions, units, invariants and golden values this
unit implements one by one. Transcribed into `docs/fairness/`.

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the gate that fails when it is violated. The engine states
no legal claim. The four-fifths line is an employment benchmark (29 CFR 1607.4(D)) and never a credit-law threshold. The outcome-
conditioned tests (equalized odds, equal opportunity, calibration within groups, AUC by group) never run on a dataset that has no
outcome. Every tolerance is a named convention, never a regulatory threshold. The golden values are reproduced by tests that recompute
them through an independent route (exact integer arithmetic, scipy, statsmodels, fairlearn, a hand computation), never by a test that
only types the answer.
