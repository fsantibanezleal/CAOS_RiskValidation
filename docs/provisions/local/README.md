# Local statutory provisions

The engine's local statutory regimes, kept apart from IFRS 9: the Chilean CMF provisions of Compendio de Normas Contables para
Bancos Chapter B-1, and the Banco de Espana Circular 4/2017 Annex 9 coverage tables. Both compute; neither is a compliance claim.
