# riskvalidation documentation

`riskvalidation` is the toolkit an independent validator of financial risk models uses: validation tests with
their exact definitions and primary sources, regulatory calculators, and reference or challenger engines. It is
consumed by the Contraste workbench and runs both in a Python pipeline and in the browser under Pyodide.

## What it is

- One result record for every test (`TestResult`), with the statistic, the null hypothesis, the reference that
  defines the test, the policy that classified it and a fingerprint of the inputs.
- Thresholds kept in versioned policy files, presented as policy and never as regulation.
- A suite runner that finishes the battery even when a test fails, so the validator sees everything.

## What it is not

- A compliance verdict. A green light means a statistic fell inside a policy band, nothing more.
- A model-training framework. Heavy learners are trained elsewhere; their outputs are validated here.
- A data service. Inputs are arrays the caller provides.
