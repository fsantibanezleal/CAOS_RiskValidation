- `simulation.ear_evar_mc_error` takes an optional `antithetic=False`. With `antithetic=True` the batches are unions of
  whole mirror pairs of an antithetic path set (as `hw1f_scenarios` returns), so the Monte Carlo standard error is not
  mis-stated by batches that hold a path and its mirror; `P` must be even and `P / 2 >= n_batches`. The result for
  `antithetic=False` is unchanged (BL-074).
